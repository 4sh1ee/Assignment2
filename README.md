## Program Design

### Inputs
- Menu choice
- Two numbers for addition, subtraction, multiplication, and division
- One number for square and cube calculations

### Outputs
- The calculated result for the selected operation
- An error message when attempting to divide by zero
- An error message for an invalid menu choice

## Program Logic

1. Display the calculator menu.
2. Ask the user to select an operation.
3. If the selected operation requires numbers, ask the user for the required input.
4. Perform the selected mathematical operation.
5. Display the result.
6. For division, check whether the second number is zero before performing the calculation.
7. Display an error message for an invalid menu choice.
8. Repeat the menu until the user selects `0` to exit.
